# Березівська молодь — сайт громадської організації

**BM-Website** — frontend-only багатосторінковий сайт для громадської організації "Березівська молодь".

Проєкт показує діяльність організації, публікує звіти та новини, приймає повідомлення через контактну форму і має просту адмін-панель для керування публікаціями, коментарями та зверненнями.

Сайт створений без SPA-фреймворків і використовує:

* HTML
* CSS
* JavaScript
* Supabase
* npm
* ESLint
* Prettier

---

## Можливості

### Про нас

* Головна сторінка з описом організації
* Фотогалерея з локальних зображень
* Спільний header і footer для всіх сторінок
* Адаптивне меню для мобільних екранів

### Звіти та публікації

* Завантаження публікацій із таблиці Supabase `posts`
* Сітка карток із фото, категорією, назвою та описом
* Пошук публікацій за назвою та описом
* Фільтр за категоріями:
  * Заходи
  * Волонтерство
  * Наша діяльність
  * Оголошення
* Перехід на окрему сторінку звіту
* Підтримка посилань на зображення з Google Drive і Dropbox
* Placeholder, якщо фото не завантажилось

### Окрема сторінка звіту

* Завантаження звіту за `id` з URL
* Відображення великого фото, категорії, назви та опису
* Відкриття фото у повноекранному перегляді
* Коментарі до конкретного звіту
* Додавання коментарів у таблицю Supabase `comments`

### Контакти

* Контактна форма з полями:
  * ім'я
  * email
  * повідомлення
* Валідація обов'язкових полів
* Надсилання повідомлень у таблицю Supabase `contact_messages`
* Стани форми: надсилання, успіх, помилка

### Авторизація

* Вхід через Supabase Auth
* Отримання профілю користувача з таблиці `profiles`
* Рольова логіка у навігації
* Підтримка ролі `admin`
* Вихід з акаунта

### Адмін-панель

* Доступ тільки для користувача з роллю `admin`
* Додавання нових звітів
* Завантаження фото у Supabase Storage bucket `post-images`
* Стиснення фото перед завантаженням через canvas
* Попередній перегляд вибраного фото
* Редагування назви, категорії та опису публікації
* Видалення публікацій
* Перегляд і видалення коментарів
* Перегляд і видалення повідомлень з контактної форми

## Архітектура

Проєкт навмисно зроблений як простий multi-page сайт.

* Немає React, Vue, Angular або іншого SPA-фреймворку
* HTML-сторінки лежать у папці `html/`
* CSS винесений у `css/styles.css`
* JavaScript розділений за сторінками у `js/`
* Supabase підключається через CDN `@supabase/supabase-js`
* Локальні скрипти підключаються як звичайні `<script>`, тому сторінки можна відкривати напряму з папки `html/`

### Дані

Основні дані зберігаються у Supabase:

* `profiles` — профілі користувачів і ролі
* `posts` — звіти та публікації
* `comments` — коментарі до звітів
* `contact_messages` — повідомлення з контактної форми
* Storage bucket `post-images` — фото для публікацій

Конфігурація Supabase зараз знаходиться у `js/common.js`.

## Supabase

Для повної роботи сайту потрібен налаштований Supabase-проєкт.

### Очікувані таблиці

#### `profiles`

```text
id
name
role
```

Використовується для визначення ролі користувача після входу.

#### `posts`

```text
id
title
category
description
image_path
created_at
```

Використовується для звітів і публікацій.

#### `comments`

```text
id
post_id
author
text
created_at
```

Використовується для коментарів на сторінці окремого звіту.

#### `contact_messages`

```text
id
name
email
message
created_at
```

Використовується для звернень з контактної форми.

### Storage

Потрібен bucket:

```text
post-images
```

Адмін-панель завантажує туди фото для публікацій і зберігає public URL у полі `image_path`.

## Ролі

### Гість

* Може переглядати сторінку "Про нас"
* Може переглядати звіти
* Може відкривати окремий звіт
* Може залишати коментарі
* Може надсилати повідомлення через контактну форму

### Admin

* Має доступ до `admin.html`
* Може створювати, редагувати й видаляти публікації
* Може переглядати й видаляти коментарі
* Може переглядати й видаляти контактні повідомлення

Роль береться з таблиці `profiles`, поле `role`.

## Важливі обмеження

* Проєкт frontend-only: власного backend-сервера немає
* Усі динамічні дані залежать від Supabase
* Адмін-доступ працює через Supabase Auth + `profiles.role`
* Дані Supabase-ключа зараз відкрито лежать у frontend-коді як publishable key
* RLS-політики Supabase потрібно налаштовувати окремо в Supabase dashboard
* Автоматичних тестів поки немає
